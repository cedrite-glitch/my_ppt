# Marp 簡報使用說明

本資料夾包含 20 頁、30 分鐘的局限空間作業危害預防宣導簡報。

## 檔案

- `局限空間危害預防_臨場護理宣導_30分鐘.md`：Marp Markdown 原始碼。
- `assets/`：由原 PowerPoint 擷取的教學圖片。

## 預覽與使用

1. 解壓縮整個資料夾，保留 Markdown 與 `assets` 的相對位置。
2. 以 VS Code 開啟 Markdown，使用 Marp for VS Code 的預覽或匯出功能。
3. 原簡報逐頁講稿、互動答案、時間與引用來源保留在 HTML 註解中，可於原始碼閱讀，並作為 Marp 講者備註。
4. 樣式使用 CSS，投影片以 `---` 分頁，右側圖片使用 Marp 背景圖片語法。

Marp 官方文件：https://marp.app/ 及 https://marpit.marp.app/

## 內容範圍

此為危害預防宣導，不取代法定教育訓練或救援資格。事故經過來自提供的情境，致災原因仍待調查。圖片為原教材示意或教材照片，並非該事故現場。若要對外公開散布，請另確認教材圖像的使用權利。
